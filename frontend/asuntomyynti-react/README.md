# Asuntomyynti React

This source is maintained inside the Drupal repository and built into the `asu_apartment_search` module.

- Production build: `make build` from the Drupal repository root.
- Local HMR development: start the Drupal stack, then run `make asuntomyynti-react-dev` from the Drupal repository root.
- Stop HMR with Ctrl+C and restore production asset loading with `make asuntomyynti-react-dev-off`.

See the repository README for setup details. Node 24 is required for local npm commands.
